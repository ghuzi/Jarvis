#Jarvis AI Assistant
## Project
Voice-enabled memory assistant using Claude API.
Single HTML file project — no frameworks, no build tools.

## Rules
- All code in one file: index.html
- Use Web Speech API for voice input (STT)
- Use SpeechSynthesis API for voice output (TTS)  
- Use Anthropic Claude API (claude-sonnet-4-20250514)
- Memory stored in JS array (no backend needed)
- UI should be dark themed, modern, minimal
- No npm, no node — pure browser HTML/CSS/JS only
